# DiPlay v0.2.44 — 在线更新弹窗视觉统一与下载体验优化

本版本重点更新车机内的软件更新界面，按深蓝背景、青色描边与按钮的设计风格统一“发现新版本”“下载并校验 APK”“准备安装/打开安装程序”等应用内弹窗。

## 主要更新

- **新版本提示**：采用圆角深蓝渐变卡片、青色边框、更新图标、版本说明与更新内容列表，并统一主次按钮布局。
- **下载进度**：显示下载百分比、已下载/总容量、传输速度，提供“下载 → SHA-256/签名校验 → 安装包准备”的阶段指示。
- **后台继续**：可以关闭进度卡片而让正在进行的下载继续；选择取消才终止该下载任务。
- **下载完成**：校验成功后以相同视觉语言显示“更新包已准备完成”，由用户点击按钮后才唤起 Android 安装程序。
- **适配与回归**：针对 Android 4.4+ 保留旧版兼容绘制；补充中文（简/繁）、英文文案和弹窗交互测试。

## 安全与兼容说明

- APK 仍必须通过来自 GitHub Release 的 SHA-256、包名、版本和签名验证。
- 更新不会静默安装；Android 提供的系统授权与安装界面无法由应用更换皮肤。
- 若老旧车机未提供可调用的系统 APK 安装器，可按应用提示使用文件管理器或 ADB 安装已校验 APK。
- 本次验证包含 Gradle 单元测试、Android Lint 与 Debug 构建；不同车机固件上的实际显示和安装行为还需要实机确认。

## 发布文件

- `DiPlay-v0.2.44-legacy-release.apk` — 本机使用原始 DiPlay 签名证书构建的正式安装包。
- `DiPlay-v0.2.44-legacy-release.apk.sha256` — 可独立比对的 SHA-256 校验值。
