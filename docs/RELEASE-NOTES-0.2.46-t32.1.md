# DiPlay v0.2.46-t32.1 — 奇骏（X-Trail T32）车机优化首发版

## 更新内容

- **画面卡顿修复**：Android 4.4 没有系统级 ChaCha20-Poly1305，而打包内 Conscrypt 从未被注册为加密 provider，导致每帧视频回退到 BouncyCastle 纯 Java 解密（日志实测 9–91ms/帧）。现改为平台实现优先、失败时使用打包 Conscrypt 的原生实现；离线基准同一代码路径快 9.1 倍（33,512 字节帧 154µs → 17µs）。
- **崩溃取证修复**：多行崩溃堆栈原先被日志脱敏整条丢弃，导致诊断报告中 `FATAL` 恒为空、拿不到堆栈。现改为逐行脱敏，并新增持久化崩溃记录，**重启后仍可导出**。
- **三指下拉设置闪退修复**：设置面板重建时对父容器的强转可能抛出 `NullPointerException`（位于手势处理器内，进程直接终止），改为安全解析并重新挂载。
- **控制通道误复位修复**：iAP2 静默 90 秒即复位链路，而奇骏上 iPhone 可静默更久、视频仍正常传输，导致正常会话被误拆（日志实测复位后视频中断约 57 秒）。现仅当 AirPlay 媒体同样静默才复位，并输出取证日志。
- **诊断修正**：`decryptMBps` 低于 1 MB/s 时不再被整数除法截断为 0；诊断报告新增 `Frame cipher:` 行，标明实际使用的解密实现。
- **仓库定位**：README 全面改为「奇骏（X-Trail，底盘代号 T32）车机优化版本」并加入商标免责声明；对外命名（仓库名、版本号、发布文件名）不再使用车厂品牌词。同时修正与该定位矛盾的原表述（BYD 定位说明、Android 9+ 安装门槛）。

## 验证说明

本次基于原作者 v0.2.46 代码合入上述修复，运行项目单元测试、Lint、Debug 和正式签名构建；实际车机表现仍需在对应 ROM 上测试。

- 单元测试：**2096 个全部通过**（较 v0.2.46 基线 2069 个新增 27 个），0 失败 0 错误 5 跳过。
- Lint：与基线一致（mobile 27 / home 5 / maphost 2，均为 Warning、0 Error）。
- 体积：`mobile-debug.apk` 18.87 MB，与基线 18.86 MB 一致。
- 全部改动**尚未在实车复测**；音频无声经完整日志复核为车机音频源路由侧问题，不涉及代码改动（见上游 issue #134 讨论）。
- 本版本为已撤回首发 tag 的**更名重发**：代码改动与撤回版本完全一致，仅对外命名改为商标中性的底盘代号 T32，versionCode 由 67 升至 68。

> ⚠️ **签名变更**：本版本使用本仓库独立的发布签名证书（别名 `t32-key0`），**不是**原作者 v0.2.21 证书，
> 因此**无法覆盖安装**旧版 DiPlay，必须先在车机【应用管理】中完全卸载旧版再安装。
> 相关说明见 [RELEASE_SIGNING.md](RELEASE_SIGNING.md) 与 README 的安装说明。
